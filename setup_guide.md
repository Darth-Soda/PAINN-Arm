# Running ST3215 servos using python

- Please refer to the [ST3215 Documentation](https://www.waveshare.com/st3215-servo.htm)

1. Install python, add it to your path during installation.
2. Download the python library from the [Documentation](https://docs.waveshare.com/Bus_Servo_Adapter_A/Resources-And-Documents).
3. Open VS in the folder STServo_Python.
4. Check Python Version “python --version”.
5. Give Permission to create Environment: “Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy Unrestricted”.
6. Create a virtual env with: “python -m venv .venv”  OR “python3 -m venv .venv” 
7. Enter/Activate already created Virtual Environment: “.venv\Scripts\Activate.ps1” for Windows
8. Enter/Activate already created Virtual Environment: “.venv\Scripts\Activate.ps1” for Windows
9. Install the requirements: python -m pip install -r requirements.txt
10. Navigate to the folder: cd stservo-env\sms_sts
11. Run any example code, REFER TO THE README FILE before you run any code.
